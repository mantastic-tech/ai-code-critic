# ai-code-critic
ai code critic powered by local ai using lm studio

## usage:
1. download lm sutido
2. download an ai model and load it in lm studio
3. in the server tap in lm studio make sure the server is running and Reachable at http://127.0.0.1:1234
4. in powershell:
  1) pip install openai
  2) python '.\Drawing App.py'
